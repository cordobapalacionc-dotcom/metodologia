La plataforma guarda sola una copia de la base de datos cada 24 horas y conserva las 30 más recientes. También puedes crear una ahora, por ejemplo antes de hacer cambios grandes.

Las copias contienen los datos personales de todas las personas. Guárdalas en un lugar seguro y no las compartas.
¿Cómo restaurar una copia?
  1. Detén el servidor (Ctrl + C en la ventana donde corre).
  2. En la carpeta backend, ejecuta npm run restaurar para ver la lista de copias.
  3. Ejecuta npm run restaurar -- nombre-de-la-copia.db. Antes de reemplazar, se guarda una copia de la base actual.
  4. Vuelve a encender el servidor con npm start.
